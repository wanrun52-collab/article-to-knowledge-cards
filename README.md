# make-knowledge-cards

这是一个用于把 Markdown 或纯文本文章转换为知识卡片的开放 Skill。

## 项目解决什么问题

阅读文章时，核心概念容易被大量背景信息和重复表达淹没。该项目让代理直接把 Markdown 或纯文本整理成结构统一、便于复习的知识卡片，并避免重复信息占用卡片篇幅。

适用场景包括课程笔记整理、文章摘要复习、历史资料提炼，以及将零散文本整理为可测验的知识点。

## 主要功能

- 提取文章中的核心知识
- 合并重复和相近内容
- 生成 5–8 张结构化知识卡片
- 为每张卡片提供核心知识、解释、例子或用例和自测问题
- 不抓取网页、不处理 PDF、不调用 Anki 或图形界面
- 不引用输入材料之外的事实

## 安装方法

将当前目录作为项目或作为代理技能包使用。目录应保持以下结构：

```text
make-knowledge-cards/
├── SKILL.md
├── README.md
├── quick_validate.py
└── agents/
    └── openai.yaml
```

将项目目录注册为代理可发现的 Skill，或将启用后的代理直接指向本目录中的 `SKILL.md`。无需安装第三方依赖。

## 使用方法

把文章内容作为文本或 `.md`/`.txt` 文件内容交给启用该 Skill 的代理，并明确要求制作知识卡片。例如：

```text
请使用 make-knowledge-cards Skill，将下面这篇文章整理成知识卡片：

<在这里粘贴文章>
```

生成结果会直接使用以下结构：

```markdown
## 卡片 1：标题

- **核心知识：** ...
- **简明解释：** ...
- **例子/用例：** ...
- **自测问题：** ...
```

## 输入输出示例

输入：

```text
缓存通过保存副本提高读取速度。缓存命中时直接使用缓存，
未命中时读取原始数据源并更新缓存。过期策略用于控制旧数据。
```

输出：

```markdown
## 卡片 1：缓存的作用

- **核心知识：** 缓存保存数据副本以提高读取速度。
- **简明解释：** 缓存减少重复访问原始数据源的时间。
- **例子/用例：** 重复打开网页时复用缓存资源。
- **自测问题：** 缓存如何提高读取速度？
```

完整输出应包含 5–8 张卡片。

## 验证

在项目根目录运行：

```powershell
python quick_validate.py
```

如需验证一份已生成的卡片文本：

```powershell
python quick_validate.py --cards .\cards.md
```
